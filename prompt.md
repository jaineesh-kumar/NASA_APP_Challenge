# AstroSim: scene prompts (copy and paste)

Each scene has a **PICTURE** prompt (paste into ChatGPT) and, where useful, a **VIDEO** prompt (paste into Google Flow). Every block is complete, so copy the whole grey box as it is.

**Save with the exact file name shown:**
- Pictures go in `public/images/`.
- Videos go in `public/video/`.

Then tell Claude which files you made.

**Order:** make **Scene 1 (mascot sheet) first**. In every later ChatGPT chat that has the crew, attach `mascot-sheet.png` and the prompt will ask ChatGPT to match it. In Flow, if you can add a starting image, use the scene's picture.

- Pictures in `public/images/`, videos in `public/video/`.
