# Media map

Every file in `public/images` and `public/video`, what it shows, its id in `src/content/media.ts`, and where it is used. Pages refer to media only by id through `src/ui/components/MediaCard.tsx`. Files are used where they are (never moved or renamed); URLs are built from `import.meta.env.BASE_URL` with `encodeURI`, so they work on a GitHub Pages sub-path.

Sizes were read from the files' own headers. ffmpeg is not installed, so no video frames were extracted; posters are matching stills where one exists.

## Rules

- Never on the Build or Rules screens (tested in `tests/ui/mediaPlacement.test.tsx`).
- Videos: muted, loop, inline, `preload="metadata"`, Play/Pause in the caption bar (44 px), no autoplay under `prefers-reduced-motion`, paused when off screen.
- A missing or broken file shows a flat placeholder (`--carbon-wash`), never a broken image.
- Colours come from the existing tokens: the card border and shadow use `--navy` (#14245c) and the placeholder uses `--carbon-wash` (#eee9ff), the closest existing tokens to the requested #14235A and #ECE6FB.
